The journey begins when a customer or shipper creates an order or label. Labels are generated when customers visit FedEx offices to tender packages or when clients such as Walmart, Wayfair, Apple, and Microsoft create labels by providing shipment details like origin, destination, weight, and dimensions, collectively known as shipment facts. Once a package is tendered, various events are generated across multiple systems, including origin, sortation, order, and delivery events. These events are aggregated into a unified view called the Rating view. This view is processed by an adapter managed by my team, transforming it into a format compatible with our orchestrator. The orchestrator, based on various parameters, determines the appropriate workflow and generates tasks, which are then distributed to worker nodes for execution. Key tasks include package rate calculation, invoicing, ledgering, and data analytics.

Our architecture employs Kafka for asynchronous communication between components, with some interactions occurring via REST APIs using Feign clients.
